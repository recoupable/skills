Recoup keeps its own output schemas, durable workflow, supported tools, opening-sequence checks, playback integration, publication permissions and billing rules. It does not import mandatory AAA/3D targets, fixed capture resolutions, model-name suppression, the companion Blender dependency, or the upstream orchestrator's exact role and verdict protocol. No reference media or upstream code is included. The API bundles the game-craft guidance through buildAndReview, which is already supplied to the builder and production generation/review calls; this file is provenance, not a runtime dependency.
