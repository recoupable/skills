## How to ground a real version

For the first bullet, cite the actual intake artifact and usage evidence. For the second, cite the
observed run and review process. For the third, cite the deployment and verified access roster.
The next-period dates and owners must come from an actual agreement or message. The fictional example
above deliberately has no spending limits, fees, quantified savings, or claims about IP ownership.
