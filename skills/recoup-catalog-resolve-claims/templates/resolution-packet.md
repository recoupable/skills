# Rights or royalty resolution packet

## Case and requested remedy

Private case ID; provider/counterparty and process; provider case ID if one exists; claimant/represented party and role; affected objects, right, territory and period; requested remedy. Distinguish an accounting request from a quantified demand.

## Observed adverse state

State the current provider record/response/hold/missing-accounting evidence and dates. Separate historical observations from current unknowns. Include material contrary evidence and unresolved facts.

## Authority and supporting evidence

Index source versions, authentic agreements/mandates/consents, relevant clauses, identities, current registration/ledger and prior correspondence. Explain exactly which proposed assertion each source supports.

## Financial basis, if applicable

Reported earnings, supported entitlement, disputed amount, accepted adjustment, remittance and observed cash remain separate by currency and period. Link controlled calculations. Identify unsupported inputs rather than using zero or asserting debt.

## Provider route and proposed disclosure

Official process/source/check date; permitted role; required form/fields/documents; recipient and any onward disclosure; supported send/file route; human-only steps. Include only necessary attachments.

## Prior actions and next bounded action

List already-sent/submitted evidence and outstanding responses. Record user-reported events separately from inspected sends. State exactly what can be done under existing authority and what remains genuinely missing.
