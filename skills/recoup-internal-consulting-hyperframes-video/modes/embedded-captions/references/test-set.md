# Portable caption test set

Use supplied approved footage or generate synthetic scenes in a scratch project. This plugin does
not include the original author's private test-video library.

Cover bright and dark backgrounds, a subject crossing the caption area, an existing bottom caption,
and a scene with a prominent sign. For each, inspect caption contrast, dwell time, clipping,
subject occlusion, and foreground/background ordering. Use the bundled preview and geometric
checks after preparing the media. A synthetic clip checks geometry and rendering; it does not
replace a realistic human-subject check for the matting model.

Record source, runtime/browser version, input plan, sampled timestamps, and actual output. Keep a
passing specimen in the selected project's established test-artifact location. Do not mark missing
fixtures or skipped checks as passes.
