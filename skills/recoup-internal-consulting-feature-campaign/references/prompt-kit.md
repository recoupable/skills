# Recoup article image prompts

Read `brand/GUIDE.md` first. Thumbnail and inline illustrations have different jobs and backgrounds.
Inspect the actual selected Finals reference before prompting. References guide the illustration
language; they do not override the white background required for inline figures.

## Thumbnail artwork prompt

Create one bold editorial thumbnail illustration for [CONCEPT], [CANVAS]. Use [SELECTED_RECOUP_COLOR]
as the background; choose any approved Recoup color, not blue by default. One oversized focal
illustration with simple, confident shapes. Choose its fills and outlines to contrast strongly with
the background. Reserve [AREA] for a large 3–6 word text hook added later. Make the concept recognizable
at 160px wide. No body copy, letters, numbers, logos, wordmarks, panels, complex scene or extra objects.

Finish with an editable DM Sans hook through HTML. The source generation intentionally has no text;
the final thumbnail must have it. Check both text and illustration contrast at thumbnail size.

## Inline illustration prompt

Create one simple editorial illustration explaining [CONCEPT] on a uniform pure white #FFFFFF
background. White object fills, deep forest/ink outlines, sky-blue connections and restrained lime
accents. Use a few clearly separated objects and one unambiguous visual relationship. Reserve [AREA]
only for necessary short diagram labels. No pale-blue fills, tinted panels, background texture,
elaborate scene, headline, letters, numbers, logos or wordmarks. Preserve [REFERENCE_ID]'s simple
illustration language while keeping the background white.

Add short editable DM Sans labels only where they help explain the figure. Inline headlines are
optional; do not repeat the article's heading. No recurring wordmark footer.

## Archetypes

| Type | Layout | Reference direction |
| --- | --- | --- |
| Thumbnail | One bold focal object plus oversized text hook, on a selected Recoup color | Blue notes / Spotlight; adapt the color deliberately |
| Flow | 2–4 simple objects left to right, clear connectors | Blueprint / Catalog index |
| Comparison | Two visually distinct alternatives, short labels if needed | Paper trail / Margin notes |
| Cycle | A few nodes on a clear loop, labels outside intersections | Signal study |
| Stack | Aligned layers, one highlighted dependency | Catalog index |
| Hub | One center and a few satellites with clear connections | Blueprint |
| Framework | Simple grouped objects or rows with concise labels | Field guide |

Use exact labels from the source and inspect at publication width. Quantitative diagrams require
verified values and deterministic editable geometry. Keep numbers out of generated-image prompts.
