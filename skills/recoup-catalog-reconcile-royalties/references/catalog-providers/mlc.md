# The MLC

Checked 2026-10-22; current form/schema and account access still need inspection.
Public search can supply observations. The Member Hub supports new works, ordinary
share claims and transfers. The Songwriter Hub for administered writers supports
catalog organization, recording match requests and writer-name/IPI correction
requests; it is not collection-share authority. [Tools](https://www.themlc.com/tools),
[Songwriter Hub](https://help.themlc.com/en/support/what-is-the-songwriter-hub-).

## New work, ordinary interest or amendment

Search and corroborate existing work identity before selecting creation. For an
existing work, prepare the documented interest against its work ID using the Claiming
Tool route, rather than registering a duplicate. Preserve writer/publisher/administrator
relationships and the actual share basis. Inspect current fields in the authorized
Member Hub before calling a packet validated. [Claiming Tool](https://help.themlc.com/en/support/what-is-the-claiming-tool).

Record exact submitted version and each history item. Registration History separates
submitted, accepted, rejected and superseded submissions. Read back the accepted
record; preserve the replaced version for later accounting. [Registration states](https://help.themlc.com/en/support/what-do-the-statuses-mean-in-registration-history).

## Recording matches

Select the eligible Member or Songwriter Hub operation. Match recording groups to
the actual composition using writer/identifier/version evidence. Preserve per-group
submitted, in-progress, accepted, partially accepted, rejected or rematched status.
A rematched group is not automatically a denied ownership claim. [Match states](https://help.themlc.com/en/support/what-do-the-statuses-mean-in-match-history).

## Transfer and adverse claims

For transfers, identify registered works, source member, effective date and authentic
authority/termination evidence. Unregistered works use registration. The documented
transfer process forwards supporting documents to existing claimants; show that
disclosure in the reviewed packet. Track source relinquishment and target acceptance
independently. [Transfer procedure](https://help.themlc.com/en/support/catalog-transfer-process-and-faqs).

For a substantive overclaim, preserve the case/work ID and competing evidence.
Contacting claimants, amending shares, relinquishing shares and uploading documents
are distinct consequential actions. Select only the requested, supported remedy;
do not reduce interests merely to make a total pass. Track record correction and
financial effect separately. [Overclaims procedure](https://help.themlc.com/en/support/what-is-an-overclaim-and-how-do-i-resolve-one-using-the-overclaims-tool).

Statements and holds require actual account/export semantics; a public search or
Songwriter Hub catalog export is not a payable ledger. This profile has no live
submission adapter, statement schema certification or authenticated outcome evidence.
