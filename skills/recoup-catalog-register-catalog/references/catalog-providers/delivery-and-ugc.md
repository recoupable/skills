# Delivered music and UGC operation profiles

Checked 2026-10-22. Establish the exact existing edition/recording, delivering party,
destination, territory and requested action before choosing a route.

## Spotify observations and corrections

Spotify directs music metadata corrections through the delivering label/distributor.
Prepare the precise old/new credit/title/availability fields and evidence, then use
that provider's verified correction route. A public Spotify listing or read API does
not authorize editing delivery. Compare distributor acceptance with subsequent
destination observations. [Metadata correction route](https://support.spotify.com/us/artists/article/fixing-problems-with-music/).

## DistroKid corrections

The documented release-edit route supports changes according to release/plan and
field constraints. Inspect the actual available operation and pending requests
before submitting a precise diff. A field that cannot use the normal edit page
needs verified support or a separately authorized redelivery plan; do not silently
delete the release. Preserve the request receipt and destination-specific observations.
[Editing a live release](https://support.distrokid.com/hc/en-us/articles/360013649333-Editing-a-Release-After-It-s-Uploaded).

## DistroKid migration

The published switch procedure uses target upload followed by old-distributor removal
and emphasizes matching audio, metadata and existing ISRCs for continuity. It does
not guarantee retained play counts/playlists. Capture current source and target
requirements, actual receipts and destination observations before applying the
authorized cutover to a particular catalog; do not generalize its timing to every
distributor. [Migration guidance](https://support.distrokid.com/hc/en-us/articles/360013648133-Switching-from-a-Different-Distribution-Company-to-DistroKid).

## UGC enrollment

DistroKid's Social Media Pack documents a paid option for existing releases covering
native UGC identification on YouTube, TikTok, Instagram and Facebook. It differs
from adding music through a platform audio library. Prepare exact release/destinations,
eligible rights and current fee/revenue terms, then inspect actual account capability
and consent before opting in. [Social Media Pack](https://support.distrokid.com/hc/en-us/articles/30785369645843-What-is-Social-Media-Pack).

Direct YouTube Content ID requires eligibility and exclusive-rights evidence; its
partner API requires appropriate Content Manager access. An ordinary channel login
does not supply that role. Review territorial exclusivity, reference eligibility,
existing claims and policy before using a supported partner/administrator route.
[Eligibility](https://support.google.com/youtube/answer/1311402?hl=en),
[partner API](https://developers.google.com/youtube/partner).

Track submitted enrollment, active reference, active policy, observed claim and
reported revenue independently. TikTok/Meta profiles here describe verified
distributor-mediated preparation, not a direct platform write API. Legal takedowns
and disputed ownership remain outside routine monetization enrollment.
