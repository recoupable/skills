# Publisher-administrator intake and accounting

Checked 2026-10-22. Resolve the represented legal entity, contract, rights/territories,
effective dates, collection tail and actual administrator before preparing intake.
Do not equate the portal user, underlying owner, payee and administration parent.

## Kobalt

The public portal page describes catalog, income and sync visibility, and identifies
roster-only knowledge resources. It does not provide a general public filing API or
field-level intake/statement contract. Use supplied exports and authenticated client
instructions/support for the actual work. [Official portal description](https://www.kobaltmusic.com/creator-portal/).

Prepare the current repertoire/intake file from those instructions, preserving work
and party identifiers, shares/basis, mandate, territory, dates, linked recordings and
authentic documents. Keep receipt of intake, local administered repertoire and
downstream society observations separate. For accounting, inventory original archive
members, quarters, revisions, currency/basis and row-level controls; select only a
tested parser matching the actual columns. Historical credits are not current cash.

## Songtrust

Songs can be added to the client catalog; that does not prove every downstream
society has accepted them. Multiple recordings of one unchanged composition attach
to that song rather than forcing duplicate song registrations. [Intake](https://help.songtrust.com/knowledge/how-many-songs-can-i-register),
[recording links](https://help.songtrust.com/knowledge/do-i-need-to-make-separate-registrations-if-there-are-multiple-recordings-of-my-song).

The current edit route depends on the song's state: Draft/Monitoring can permit
client edits or return to draft, while later states require checking the supported
assistance route. Preserve current status and requested diff before changing it.
[Editing information](https://help.songtrust.com/knowledge/how-can-i-edit-split-information).

This is a distinct administrative preparation profile, not proof that a Songtrust
statement format has been implemented or tested. Unknown accounting formats need
an explicit source-column/basis review and controls before acceptance.

## Intake and accounting handoff

Deliver the exact requested file/packet, rules/source version, missing fields,
submitted receipt if one exists, provider decision and observed state. Missing consent
blocks that action without preventing independent statement analysis. For a move,
retain signed release/termination, effective boundaries and old/new collection tails.
Do not send a second intake or message when the case already records one pending.
