# Recoup editorial figure kit

Read brand/GUIDE.md first; this kit owns concepts, not a second palette. Exact type/logo comes from
staged recoup-brand resources. Prefer local editable HTML/SVG for a diagram; imagery generation is
optional for the environment or hero. Brand Studio Finals are references, not new-output approval.

## Image environment prompt

Recoup editorial world: clear daylight, sky-blue atmosphere, considered working papers and soft
physical depth. One concrete visual metaphor for [CONCEPT], composed for [CANVAS]. Reserve [AREA]
for typeset labels. White/pale-blue paper, deep forest/ink anchors, limited lime detail. Use supplied
approved [REFERENCE_ID] for material and composition. No text, letters, logos, numbers, fake receipts,
robot/mascot or generic neon orb. The exact headline and supplied Recoup mark will be overlaid later.

## Archetypes

| Type | Layout | Reference direction |
| --- | --- | --- |
| Hero | One metaphor/working object and one typeset title; no crowded process map | Blue notes / Spotlight |
| Flow | 2–4 paper nodes left to right with sky connectors; lime for the decision | Blueprint / Catalog index |
| Comparison | Two columns, plain headings and one concise conclusion | Paper trail / Margin notes |
| Cycle | 4–6 nodes on a clear loop, labels outside intersections | Signal study |
| Stack | Aligned layers, one highlighted dependency, meaningful brace | Catalog index |
| Hub | One center and a few satellites with unambiguous connections | Blueprint |
| Framework | Numbered rows; labels concise, body in DM Sans | Field guide |

All eleven approved directions remain options. A warm-paper or forest design may follow its
reference's deliberate derivative colors. Never force it back to unrelated grey/marker examples.
Use exact labels from the source, escape text, inspect at publication width. Add a source note for
quantitative claims. Keep sources editable and numbers out of generated-image prompts.
