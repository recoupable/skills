# Organize my publishing

Read `references/music-business-records.md` before starting; it defines supported
file-review and hosted-save routes, source handling and completion checks.

## Result

Give the writer/publisher a composition inventory they can use to check registrations
and administration, with each missing detail tied to a particular work or relationship.

## Workflow

1. Identify the writer/publisher and intended repertoire, supplied exports/documents,
   available party IDs and authorized workspace. Distinguish the publishing company
   from a label or login account; confirm any mandate from actual supplied agreements.
2. Read work lists, split sheets, agreements and requested accessible registry exports.
   Preserve source versions and row/page/clause references. Keep public registration
   observations separate from signed agreements and user assertions; unavailable
   registries remain unchecked, not “unregistered”.
3. Build one composition table: title/alternate title, supplied ISWC/work IDs,
   writers and party identifiers, publishers, explicit interests with basis/territory/
   dates, administrator and mandate reference, registration source/status/date, linked
   recordings/ISRCs and unresolved matches. Support works with no recording or ISWC.
4. Keep recordings separate: several recordings may embody one composition and a
   recording may contain several works. Do not duplicate compositions for every
   release or combine same-title works without adequate identity evidence.
5. Reconcile only comparable interests and registration claims. Highlight unmatched
   party IDs, conflicting shares, missing split sheets, absent registration references,
   uncertain recording/work matches, and unclear or expired administration mandates.
   Name the exact document or confirmation needed. Missing input does not establish
   missing payment or a collection opportunity.
6. Discover scoped repertoire/import operations before saving. Do not create artists
   for publishers, grant software access from an agreement, or manufacture ISRCs to
   fit an artist-only catalog tool. If hosted support is unavailable, deliver the private
   worksheet with unresolved items and identify which records still need importing.
7. Read back any hosted records and preserve version/history. Give another authorized
   session the saved identifiers or private report location to continue the work.

## Handoff

Return the repertoire, source coverage, concrete missing/conflicting items per work,
and the next bounded registration-review or document request. Describe statuses as
“listed in supplied export”, “checked at [registry/date]” or “not checked”, rather than
claiming universal registration coverage. Do not submit registrations, assert collection
authority, distribute royalties, calculate a recovery total or value an acquisition.

Example: a 40-work export with six missing ISWCs returns all 40 works and six missing-ID
items; it does not claim those six works are unregistered or owed money.
