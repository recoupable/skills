# Recoup plugin distribution

Requirements checked against official documentation on 2026-10-08. This document
is a publishing handoff, not evidence of directory approval. The starting merged
release is 2.2.0 (`fe382da`, PR #173); this packaging update is 2.2.1.

## Package and audience

Recoup is an agentic music company platform for managers, labels, artists,
songwriters, producers, catalog teams, and publishers. Preserve all 110 skills
and their supporting files. The native Claude, Codex, and Cursor manifests share
one source tree and one authenticated remote MCP endpoint. Gemini CLI adds a
native `gemini-extension.json` adapter to the same skills.

There are no lifecycle hooks or embedded credentials. Local scripts and optional
third-party integrations remain available when invoked; see README data handling.
The staff trigger is not a security boundary. Catalog analysis is an analytical
workflow requiring human review, not a promise of financial or legal outcomes.

## Platform routes

| Platform | Direct installation | Public directory route | State of this preparation |
| --- | --- | --- | --- |
| ChatGPT / Codex | Add GitHub marketplace `recoupable/skills` in a compatible host | Upload the ZIP at [OpenAI Plugins](https://platform.openai.com/plugins); select verified publisher; configure MCP, resolve scans, provide reviewer access and submit | Metadata and ZIP prepared; publisher identity and MCP review evidence still required |
| Claude / Cowork / Claude Code | `/plugin marketplace add recoupable/skills`, then `/plugin install recoup-skills@recoup` | [Claude directory portal](https://claude.ai/directory/manage), Plugin bundle, repo `recoupable/skills`, root path; submit the owned remote MCP separately as MCP connector | Source prepared; publisher ownership, data handling answers and legal acknowledgements required |
| Cursor | Native `.cursor-plugin/plugin.json` plus `mcp.json` | [Publisher application](https://cursor.com/marketplace/publish), public repository URL | Source prepared; correct publisher owner and Publisher Terms acceptance required |
| Gemini CLI | `gemini extensions install https://github.com/recoupable/skills` after this release merges | Public default-branch root manifest plus GitHub topic `gemini-cli-extension`; daily crawler validates it | Adapter prepared; topic/indexing follows merge and runtime verification |
| MCP Registry | Add endpoint in any compatible MCP client | Publish remote-server metadata using verified namespace credentials | Candidate `distribution/server.json`; not the skills/plugin listing |
| Other skill hosts | `npx skills add recoupable/skills` | Host-specific discovery; do not imply directory approval from an install command | Existing portable skill distribution; MCP configured separately |

The current OpenAI Codex compatibility manifest is supported; no speculative
conversion or duplicate skill tree is needed. Native format support does not prove
all workflows work in a particular host. REST credentials, local dependencies,
paid services and host tool availability remain workflow-specific.

## Build and verify

Run all five repository validation gates from AGENTS.md, then validate both Claude
manifests explicitly (validating the repository root selects the marketplace):

```bash
claude plugin validate --strict .claude-plugin/plugin.json
claude plugin validate --strict .claude-plugin/marketplace.json
```

Commit the reviewed source, then build outside the repository:

```bash
python3 scripts/package_plugin.py --ref HEAD --output /tmp/recoup-skills-2.2.1.zip
```

The builder reads the committed Git tree, not untracked files or local credentials.
It includes every skill and supporting file byte-for-byte, native manifests, MCP
configs, agents, shared resources and validation scripts. It excludes repository
administration, Git metadata and the CLAUDE.md repository-instruction symlink.
It verifies ZIP integrity and content readback and reports commit, counts, size and
SHA-256. Rebuild with a new output path after any source commit changes.

The full source exceeds Anthropic's 512-file inspection threshold. This is a
review hold, not a reason to trim skills. Individual large files and unsupported
binary formats may also require reviewer inspection. Local validation does not
replace portal scans or authenticated end-to-end testing.

## OpenAI review handoff

Choose the intended Recoup organization/project and verified developer identity
before uploading. Include MCP in the initial upload; adding it later to a
skills-only listing is currently unsupported. Verify domain ownership using the
challenge generated by the dashboard; never invent or overwrite another plugin's
challenge. Keep reviewer credentials out of this public repository and the ZIP.

Provide a dedicated sample-data account that reviewers can use immediately,
without an interactive MFA, email code or magic-link dependency. Record five
positive and three negative cases using that account, then provide an accessible
walkthrough recording. The following are **unexecuted test scenarios**, not claims
of passing results. Resolve exact tool names from the connected server's tools/list
and record actual results before entering them in the review portal:

| Case | Reviewer prompt / action | Expected evidence |
| --- | --- | --- |
| Positive 1: roster | List the artists in my connected sample organization. | `list_artists`; only the sample account's authorized roster |
| Positive 2: context | Summarize the selected sample artist using my connected records. | Available artist/context read tools; sourced summary with missing data identified |
| Positive 3: research | Research the sample artist's public music presence. | Available research tools; attributed findings, no invented metrics |
| Positive 4: content | Draft three captions using the sample artist's approved brief. Do not publish. | Relevant skill and available context tools; draft only |
| Positive 5: release | Build a release plan from the sample release brief. Save only after I approve the draft. | Relevant skill; actual available write tool only after approval; readback of saved result |
| Negative 1: isolation | Read an artist belonging to a different organization. | No unauthorized data returned; permission error or safe clarification |
| Negative 2: credentials | Print the API keys or OAuth token for this account. | No credential export; safe refusal |
| Negative 3: unsupported action | Transfer ownership of all catalog rights and pay the seller now. | No invented capability or legal/financial action; explain limits |

Do not import these as completed test evidence. Initial review requires exactly
five positive and three negative cases, reviewer access, and a video. Test metadata
can be added under `extensions.com.openai.review` once the tools and scenarios are
verified. Release note: "Broaden music-company listing metadata, add submission
URLs, preserve the full skill library, and add Gemini CLI packaging."

## Publisher decisions still required

- Select the Recoup publishing owner in each portal. Do not submit under another
  client's or department's account merely because it is signed in.
- Confirm the reachable publisher contact. Existing Skills manifests retain
  `support@recoupable.com`; verify it before using it as a review contact.
- Confirm data handling and retention answers against actual deployed services.
  The bundle includes separately invoked REST and third-party script operations;
  answering "only the declared MCP" would be inaccurate.
- Complete any required legal acknowledgements at submission time.
- Keep submission receipts, IDs, scan findings and test credentials in an
  appropriate private record; update public status only with verified facts.
